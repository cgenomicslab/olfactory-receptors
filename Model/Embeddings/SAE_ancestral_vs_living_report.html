Analysis note · Olfactory-receptor evolution

Do reconstructed ancestral ORs show gained or lost SAE features?

A first pass comparing sparse-autoencoder feature fingerprints of living human olfactory receptors against their reconstructed ancestors — and why the apparent signal is reconstruction noise, not evolution.

2026-07-23 ESM-C 6B · SAE layer 60 · k64 · 16 384 features 865 seqs — 433 living + 432 ancestral Biohub API env: esmsae

Bottom line

The current pipeline is measuring ancestral-reconstruction noise in the variable regions of the protein — not evolutionary turnover of SAE features.

This is a clean negative result. The sanity checks pass, so the tooling works; the finding tells us precisely which two things to fix before any gain/loss claim can stand: the flicker-prone presence threshold, and reliance on ASR sequences for the poorly-reconstructed loops and termini.

01

What we ran

Each receptor sequence was passed through ESM-C 6B, and a sparse autoencoder re-expressed every residue as a 16 384-dimensional feature vector (top-64 active per residue). We collapsed each protein to a presence fingerprint — the set of features that fire at least once — and compared living receptors to ancestors both globally and branch-by-branch on the reconstructed OR tree.

02

Sanity check: the SAE reads ORs correctly

The features present in 100% of receptors are exactly the right ones. The single most telling feature, 16366, is described as “whole-protein activation on seven-helix chemosensory receptors” — the olfactory-GPCR identity signal, firing across the entire chain. Feature 6346 cleanly picks out TM4 of 7-TM GPCRs. The remaining ubiquitous features are the generic 7-transmembrane scaffold: helices, helix termini, membrane-interface boundaries.

Caveat carried forward: some auto-descriptions are off-target (methyltransferase, AAA+, immunoglobulin-V). These come from each feature’s top-activating proteins across the whole database, which are not ORs — polysemantic leakage. Trust the membrane / 7-TM descriptions; discount the stray-enzyme ones.

03

Ancestral vs living: near-identical

Plotting per-feature prevalence in ancestors against living receptors puts every point on the diagonal. No feature swings from absent to universal. The largest differences are modest, graded shifts of ~20–25 percentage points — and, tellingly, they concentrate in low-complexity, disordered, terminal and loop detectors on both sides:

  • “more in living” leans on features like 10831 (Pro/Gly-rich low-complexity), 7207 (disordered low-complexity), 13101 (N-terminal submodule).
  • “more in ancestral” leans on 1708 (Ser/Pro/Gly/Thr-rich low-complexity), 10653 (Gly/Ser/Thr-rich), 10229 (membrane-interface loops).

Those are precisely the regions ancestral sequence reconstruction handles least reliably (N/C-termini, ICL3, variable loops; ML reconstruction also biases composition toward common residues). The conserved TM core stays constant — it was the invariant scaffold from step 02.

04

The smoking gun: threshold flicker

The branch-by-branch view makes the artifact undeniable. A genuine evolutionary gain or loss is rare and clade-coherent — a feature appears once on a branch and is retained across that whole subtree. Instead, the top “gained” and “lost” features each flip independently on 140–170 of 864 branches (~16–20% of the tree):

A feature switching on a fifth of all branches is not evolving — it is hovering at the presence threshold (ACT_THR = 0.01, firing on a single residue is enough) and being tipped on and off by per-residue wobble, amplified by reconstruction. It is the same low-complexity features from step 03, seen a second way.

05

Diagnosis

Two failure modes compound:

  • ASR-then-embed stacks two error sources — sequence reconstruction error, then SAE feature error — and both bite hardest in the variable regions that carry most of the apparent signal.
  • Binary “fires anywhere” presence is hypersensitive — one residue crossing 0.01 flips a whole-protein call, so features near the boundary flicker across the tree as noise rather than as phylogenetic events.

Nothing here contradicts the biology; there simply is no clean feature-turnover signal to report yet, and the modest differences are best explained by the method, not by OR evolution.

06

What we fix next

All offline — no further API credits. The goal is to replace “which features differ on average” (noise-dominated) with “which features show a coherent, single-origin gain or loss on the OR tree.”

Composition diagnostic

Compare ancestral vs living on length, low-complexity (SEG) fraction, and amino-acid composition. If ancestors are systematically biased, that directly explains the low-complexity-feature signal.

Homoplasy filter — the decisive step

Build binary presence states for the 433 living leaves only, run Fitch parsimony, and score each feature’s consistency index. Features flipping 169× score ≈0 (noise); a feature gained once and retained scores ≈1. Rank by CI, then check whether the coherent survivors map onto the Class I / II split.

Robust presence + ASR-free cross-check

Require a feature to fire on ≥ 3 residues (or a higher max activation) before it counts as present. Then compare parsimony-inferred ancestral states — reconstructed from the tree, independent of ASR sequences — against the ASR-then-embed states, feature by feature. Agreement earns trust; disagreement flags the artifact.

SAE feature descriptions are automatically generated hypotheses from large-scale activation patterns, not experimental annotations — treat them as leads. Prevalence and gain/loss counts depend on the activation threshold and the presence definition, both of which the next iteration hardens.
